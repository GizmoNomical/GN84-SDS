# GN84-SDS  
### Synced Death Sounds

Simple Project Zomboid mod that allows nearby players to hear zombie death sounds.

By default, zombie kill sounds are only heard by the player who killed the zombie.  
This mod plays those sounds at the zombie’s location so other nearby players can hear them.

---

## 🧩 Features

- When a player kills a zombie:
  - Plays death sounds (`HeadStab`, `HeadSmash`) at the zombie  
  - Makes the sound audible to nearby players  

---

## ⚙️ Requirements

- Project Zomboid (Build 41)

---

## 📝 Notes

- Client-side only  
- Only triggers for the player who killed the zombie (prevents duplicate sounds)
